# Framework System

## Purpose
Frameworks extend the base planner with optional planning/scoring layers. They should improve reflection and decision quality without replacing the week-first planning experience.

## Active Frameworks
1. [Category Framework](/Users/sunnyto/Documents/dev/day_planner/docs/product/frameworks/category.md)
2. [Journaling Framework](/Users/sunnyto/Documents/dev/day_planner/docs/product/frameworks/journaling.md)

## Integration Rules
1. Core week planning must function with no frameworks enabled.
2. Frameworks must be independently enabled/disabled.
3. Framework output must be understandable and auditable by the user.
4. Frameworks must not degrade week-view clarity or performance.
